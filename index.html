        A carregar os serviços partilhados…

        Configurar o Firebase pela primeira vez

        Crie um app Web e o banco Cloud Firestore no console Firebase. Cole a configuração em firebaseConfig, no início deste HTML. Para este projeto sem autenticação, publique estas regras simples:

        rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{name} {
      allow read, write: if true;
    }
    match /configuracoes/sistema {
      allow read: if true;
      allow write: if false;
    }
  }
}

        Estas regras permitem acesso público aos perfis e leitura da configuração partilhada. Edite os serviços apenas no console Firebase: configuracoes/sistema, campos gemini_key, tmdb_key, spotify_client_id e spotify_secret. As chaves são acessíveis aos navegadores que usam o app.
